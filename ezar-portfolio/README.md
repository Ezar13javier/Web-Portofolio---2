# Ezar Javier — Portfolio

Static portfolio website rebuilt from the supplied UI reference.

## Struktur

- `index.html` — struktur dan konten halaman
- `style.css` — layout, responsive design, hover states
- `script.js` — tahun footer dan smooth-scroll
- `assets/profile.png` — crop foto dari UI reference
- `assets/project-1.png` — thumbnail project 1
- `assets/project-2.png` — thumbnail project 2
- `assets/project-3.png` — thumbnail project 3

## Menjalankan

Tidak membutuhkan build tool.

Cara tercepat: buka `index.html` di browser.

Atau gunakan local server:

```bash
python -m http.server 8000
```

Lalu buka `http://localhost:8000`.

## Yang perlu kamu ganti

1. `YOUR-EMAIL@example.com` di `index.html` dengan email sebenarnya.
2. Link social media di bagian footer.
3. File CV menjadi `assets/Ezar-Javier-CV.pdf`.
4. Thumbnail project dengan screenshot project final yang lebih tajam bila sudah tersedia.
5. Detail project dan tanggal pengalaman sesuai CV aktual.
